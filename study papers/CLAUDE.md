# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a research reference collection focused on **Gaussian Splatting** and **NeRF (Neural Radiance Fields)** — 3D scene reconstruction techniques. It contains PDFs of academic papers and a README that tracks links to papers, GitHub repos, and demos shared via email.

## Structure

- `README.md` — index of links and resources, organized by email/date batches
- `email - 19.03/` — papers from March 19 batch (Gaussian Splatting intro, NeRF)
- `email - 30.03/` — papers from March 30 batch (macro GS, DropGaussian, OMG, micro-macro GS)

## Conventions

When adding new papers or resources:
- Add entries to `README.md` under a heading matching the folder name (e.g., `# email - DD.MM`)
- Store PDF files in the corresponding dated folder
- List GitHub repo, arXiv link, or project page URL alongside the paper title in the README
